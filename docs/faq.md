# Frequently Asked Questions (FAQ)

## Common Questions
* **How is this website hosted?**
  It is automatically built and hosted directly from the `/docs` folder using **GitHub Pages**.
* **How do I update the live site?**
  Simply commit changes to any `.md` file inside `docs/` using `git push` or the GitHub web editor.
